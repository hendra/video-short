# Free TTS (Gemini-first) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace ElevenLabs as the default voiceover API with a zero-billing primary (Gemini TTS via Google AI Studio) plus two optional free-quota backups (Google Cloud TTS, Azure Speech F0), keeping an identical `npm run tts -- <id>` workflow.

**Architecture:** `scripts/tts.mts` becomes a thin dispatcher; provider clients live in `scripts/lib-tts.mts`; the offline timing engine is extracted from `align-local.mts` into `scripts/align-core.mts` and reused. Audio is staged to a temp file and analyzed **before** `public/<id>/vo.mp3` is replaced, so the committed audio+alignment pair can never go stale.

**Tech Stack:** Node ≥ 20.19, tsx, Remotion, FFmpeg (already bundled/used), REST via `fetch` (no new dependencies), `node:test` for unit tests (no new dependencies).

**Spec:** `docs/superpowers/specs/2026-11-11-free-tts-design.md` — implementers read the spec first; where the spec and this plan differ, the spec wins and the plan must be corrected.

## Global Constraints

- `vo.mp3` naming preserved everywhere; committed videos' `vo.mp3` files are never regenerated.
- No new runtime or dev dependencies. REST via `fetch`; WAV header built inline; MP3 via FFmpeg (system or `npx remotion ffmpeg` fallback — reuse the `ffmpeg()` helper pattern from `scripts/align-local.mts`).
- Never log API keys; error output carries provider name + HTTP status + body snippet only.
- `alignment.json` `source`: `"estimated"` for gemini/gcloud/azure (same semantics as `align-local`), `"tts"` for elevenlabs only.
- **Write order is a hard guarantee:** stage `vo-<id>-staging.mp3` in `os.tmpdir()` → run silencedetect/DP analysis on it → rename into place + write `alignment.json` together. On analysis failure: committed pair untouched, staging moved to `os.tmpdir()/vo-<id>-failed.mp3`, exit 1, **no provider fall-through** (user ruling), no blind estimate written.
- `auto` chain: gemini → gcloud → azure; elevenlabs is **never** in `auto`; `--provider=` flag overrides; default `auto`, or `TTS_PROVIDER` env; flag wins over env.
- Indonesian content only; `languageCode`/`xml:lang` = `id-ID` everywhere.
- Docs flip to Gemini-first at merge time (user ruling); ElevenLabs is kept optional and documented as legacy.
- `npm run lint` = `eslint src && tsc && tsc -p scripts`; must pass after every task.
- Tests run with `tsx --test` against `node:test`; no network is touched by tests (fetch is always mocked or injected).

## Review Focus

1. **All providers unconfigured / missing env** (no keys anywhere) — user must get a clear exit 1 listing what was skipped, and nothing written to `public/` or `src/videos/`. → test in Task 3 (`synthesizeAndPublish` all-skipped case) + Task 4 (CLI exit code).
2. **Synthesis succeeds but silencedetect finds fewer segments than lines** (Gemini pauses too short) — committed `vo.mp3`/`alignment.json` stay untouched; staging lands at `os.tmpdir()/vo-<id>-failed.mp3`; exit 1. → test in Task 2.
3. **Malformed provider responses** (bad base64, empty audioContent, non-2xx, bogus payload) — each provider throws one-line errors with status; the thrown message never contains the API key. → tests in Task 2.
4. **Provider selection surprises** — `auto` never calls ElevenLabs even when `ELEVENLABS_API_KEY` is set; flag `--provider=gemini` hard-pins (no fallback); bogus `--provider=foo` → usage error; empty naskah exits before any provider call and never writes anything. → tests in Task 3.
5. **FFmpeg missing on a machine without system ffmpeg** — WAV→MP3 transcode falls back to `npx remotion ffmpeg` (pattern exists in `align-local.mts`); if neither works, error is explicit, staging preserved in tmp, committed files untouched. → verify manually by `PATH`-stripping in Task 4 (no new test infra).

On success: base64-decode `candidates[0].content.parts[0].inlineData.data` → PCM; wrap in WAV (24000 Hz, mono, 16-bit; `riff`/`WAVE`/`fmt `/`data` header — same pattern as `music.mts`). "id-ID-Wavenet-B" }, audioConfig: { audioEncoding: "MP3" } }`. MP3 bytes from base64 `audioContent`. Return `{ audio, ext: "mp3" }`.
  - `synthesizeAzure(text: string): Promise<SynthResult>` — POST `https://${AZURE_SPEECH_REGION}.tts.speech.microsoft.com/cognitiveservices/v1`; headers `Ocp-Apim-Subscription-Key`, `Content-Type: application/ssml+xml`, `X-Microsoft-OutputFormat: audio-24khz-48kbitrate-mono-mp3`; SSML `<speak version="1.0" xml:lang="id-ID"><voice name="${AZURE_SPEECH_VOICE ?? "id-ID-ArdiNeural"}">${xmlEscaped(text)}</voice></speak>`. Return MP3 buffer.
  - `synthesizeElevenLabs(text: string): Promise<SynthResult>` — **moved verbatim** from current `scripts/tts.mts` (env keys, fetch URL, with-timestamps, words mapping to `TimedWord[]`).
  - `hasProviderEnv(p: TtsProvider): { ok: boolean; missing: string }` — gemini: `GEMINI_API_KEY`; gcloud: `GCLOUD_TTS_KEY`; azure: `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`; elevenlabs: `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`.
  - `stageToMp3(audio: Buffer, ext: "mp3" | "wav", destPath: string): Promise<void>` — if `ext === "mp3"`: `fs.writeFileSync(destPath, audio)`. Else write `destPath + ".wav"` to `os.tmpdir()`, then `ffmpeg(["-hide_banner","-y","-i",wavPath,"-codec:a","libmp3lame","-b:a","128k",destPath])` (spawnSync, `npx remotion ffmpeg` fallback per `align-core.ffmpeg` pattern), unlink the wav.
  - `xmlEscape(s: string): string`.
