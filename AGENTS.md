# AGENTS.md — explainer-3d

Vertical (1080×1920) 3D explainer Shorts for YouTube/TikTok: Remotion + React Three Fiber, AI voiceover (Google AI Studio TTS, free) with per-word timing, karaoke captions. Content language is Indonesian (santai-profesional). Channel brand: prefix `Kali Aja `, accent `Tau`.

Requires Node ≥ 20.19. Verification is `npm run lint` + `npm test` (node:test, offline/mocked) + bundling + eyeballing stills.

## Commands (all repo-specific)

- `npm run dev` — Remotion Studio. `predev` auto-synthesizes missing `public/<id>/music.wav` (local, no API key needed).
- `npm run lint` — the only static check: `eslint src && tsc && tsc -p scripts`. Run this after any change. (`scripts/` has its own tsconfig because it uses `allowImportingTsExtensions`; root `tsc` covers only `src/`.)
- `npm run render -- <id> out/<id>.mp4` — `--gl=angle` (GPU) by default. Server/CI without GPU: add `--gl=swangle` (much slower, ~0.8 s/frame). CI (`.github/workflows/video.yml`) uses `--gl=vulkan` with swangle fallback (verified on the self-hosted runner).
- Video pipeline (per `<id>`, in order): `npm run tts -- <id>` *or* `npm run align -- <id> <vo.mp3>` → `npm run timeline -- <id>` → `npm run music -- <id>` (only if duration changed) → dev/render. `npm run tts` defaults to gemini (Google AI Studio free key), auto-falling back to `gcloud` then `azure` if keys exist; pin with `--provider=`. Timing comes from the built-in offline aligner (±0.2 s words) — no timestamps API needed. There is **no word-alignment dependency** for the default path.
- `npm run credits` — legacy ElevenLabs quota check (only relevant with `--provider=elevenlabs`).
- CI: `.github/workflows/video.yml` (Cloudflare cron → self-hosted runner → full free pipeline) — runbook: `ops/README.md`.
- Args always go through `--`: `npm run <script> -- <id>`. Scripts take the video id; folders are in `src/videos/`.
- Smoke-check a build without rendering: `npx remotion bundle --out-dir /tmp/rbundle`, then `npx remotion still <bundle> <id> <out.jpg> --frame=<f>` and view the image.

## Pipeline & generated files

- `naskah.txt` lines must match `NN  text` (2-digit number, two spaces). Other lines are ignored. Bind all animation timing to script lines via `L(n).s` / `L(n).e` (see `Ctx` in `src/engine/types.ts`), never raw seconds — VO regeneration re-times everything automatically.
- `timeline.json` is **generated but committed** — re-run `npm run timeline -- <id>` after editing `naskah.txt`, `config.json`, or `alignment.json`, and commit the result.
- `alignment.json`, `naskah.txt`, `config.json`, `vo.mp3` are committed. `public/*/music.wav` is gitignored (regenerated by `predev`/`prerender`). `out/` is gitignored.
- `.env` (gitignored) holds `GEMINI_API_KEY` (primary, free at aistudio.google.com/apikey) and optional `GCLOUD_TTS_KEY` / `AZURE_SPEECH_KEY`+`AZURE_SPEECH_REGION` backups. `ELEVENLABS_*` keys are optional/legacy (`--provider=elevenlabs`). Scripts load `.env` themselves via `loadDotenv` in `scripts/lib.mts` — no dotenv dependency. Never commit or print keys.

## Architecture

- `src/engine/` is video-agnostic: `Explainer.tsx` (ThreeCanvas + overlays + audio), `overlays/Overlays.tsx` (header, callouts, chips, karaoke caption, CTA, SAFE text areas), `kit.ts` (low-poly building blocks), `math.ts` (deterministic helpers, `rng`), `types.ts` (`VideoDef`, `Timeline`, `Ctx`).
- `src/videos/<id>/` per video: `naskah.txt`, `config.json` (`shots: [[shotId, firstLine], …]` + `tail`), `state.ts`, `world.ts` (scene built once, `update(t)` per frame), `shots.ts`, `index.ts`. Registry: `src/videos/registry.ts` — a video exists only if registered there; composition id = registry key.
- FPS 30, 1080×1920, duration = `ceil(timeline.dur * 30)` (`src/Root.tsx`).
- `scripts/*.mts` run with `tsx`; shared helpers/env loading in `scripts/lib.mts`.
- `public/fonts/` = Inter + DejaVu Sans Mono, bundled so renders are identical offline. Don't swap font sources.

## Hard rules (render correctness)

- **Everything visible must be a pure function of `t` (seconds).** No `Math.random()`, `Date.now()`, or cross-frame state — Remotion renders frames in parallel, out of order. Use `rng(seed)` from `engine/math.ts`.
- Particles with changing speed: integrate the rate from 0 to `t`, never `t * speed`.
- Caption: one chunk at a time, never two; ≤ 5 tokens per chunk, except spelled-out number runs are joined and may exceed 5 words; keep `line-height: 1.8` in `Overlays.tsx`; don't move captions above y≈1270 or shrink SAFE areas (YouTube UI covers edges).
- Callout anchors should sit inside the zone between header bottom and y≈1240, or the overlay auto-pinning/hide logic will drop or edge-pin them. Max 3 callouts per shot; `orange` = focus, `red` = danger. No stacked/overlapping text.
- Diorama schematic maps get `tag: "ILUSTRASI"`.
- After building a video or changing scenes: render stills of the busiest frame of each shot and eyeball them before a full render (full swangle renders take ~35–40 min).

## Publishing & automation

- `docs/AUTOPILOT.md` is the scheduled-task runbook (Mon/Wed/Fri) for end-to-end production → YouTube + TikTok. If asked to "make a video" end-to-end, read it first — topic rules, quality bar, commit/push-to-`main` expectations. Publishing mechanics (Buffer GraphQL, Cloudinary signed upload, token scopes, poll `post(input:{id})`): **`docs/PUBLISHING.md`** (tested 2026-11-11) — read BEFORE any upload; no "| 11.ai" suffix for Gemini VO (ElevenLabs-Free only).
- `docs/ledger.md` tracks every produced/published video — add a row when publishing; commit `src/videos/<slug>/*`, `public/<slug>/vo.mp3`, registry, and the ledger (never `out/` or `music.wav`).
- Reference implementations: `src/videos/terowongan-mrt` (newest, most complete), `src/videos/rumah-pompa` (original template example).

## Gotchas

- Remotion composition props must be JSON — compositions only carry `videoId`; the video object is looked up in `VIDEOS` inside `Explainer.tsx`.
- `build-timeline` fails if fewer than 80% of script words match the alignment (then naskah.txt ≠ spoken text); the rest are interpolated. It does not check total duration — verify 60–90 s yourself in `timeline.json`.
- TTS failure on all providers (or a provider analysis failure): the committed `vo.mp3`/`alignment.json` pair is left untouched — fresh audio lands in `os.tmpdir()/vo-<id>-failed.mp3`. Don't hand-edit `.env` mid-run; fix the key/quota and re-run.
- Local Node needs no special proxy; cloud workspaces need `NODE_USE_ENV_PROXY=1 NODE_EXTRA_CA_CERTS=/root/.ccr/ca-bundle.crt` for the TTS provider API calls (see AUTOPILOT §1).
